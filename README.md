# OCS DeepSeek 本地版

基于 [OCS 网课助手](https://github.com/ocsjs/ocsjs) 5.4.2 的修改版，支持在脚本设置中填写个人 DeepSeek API Key。题目及选项将发送至 DeepSeek，API 费用由 Key 所属账户承担。

## 安装

安装 Tampermonkey 后安装 `ocs-deepseek.user.js`。在脚本的设置中选择“配置或测试 DeepSeek”，填写自己的 API Key 并测试连接。默认不自动提交答案。AI 结果可能有误，请自行核对。
